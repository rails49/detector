# Issue tracker

Issues are GitHub issues in rails49/detector. The `gh` commands and the
wayfinding operations are the organisation's
[issue-tracker.md](https://github.com/rails49/.github/blob/main/docs/agents/issue-tracker.md). This file holds what detector adds.

Issues from before the split from rails49/occupancy are occupancy's: write
them `rails49/occupancy#N`. Occupancy #115, #125 and #172 moved here as #3, #2
and #10, and #132's open half is #7. ADRs and research notes keep their old
link text (org ADR-0025 rule 5); follow the link.
